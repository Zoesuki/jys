| 项目 | 内容 |
| --- | --- |
| 版本 | v1.0（2026-10-07，随模块实施演进） |

## 1. 通用规范

### 1.1 基础约定
- 前缀 `/api`；资源名复数小写 kebab-case；动作类资源用动词子资源（如 `POST /activities/{id}/registrations`）；
- 认证：`Authorization: Bearer <JWT>`（2h）+ Refresh Token；管理后台接口额外要求 2FA 会话标记（NFR-07）；
- 时间一律 ISO 8601（含时区偏移）；金额/经验为整数；ID 为数字；前端按 `ApiResponse.data` 取数。

### 1.2 统一响应
```json
// 成功
{ "code": "OK", "message": "ok", "data": { }, "requestId": "uuid" }
// 失败（HTTP 状态码同步表达类别）
{ "code": "FORUM-2001", "message": "该版块仅成员可见", "data": null, "requestId": "uuid" }
```

### 1.3 分页约定
请求：`?page=1&pageSize=20`（默认 1/20，最大 100）；排序 `&sort=latest|hot` 等按接口定义。
响应：`data = { "items": [...], "total": 128, "page": 1, "pageSize": 20 }`（原型分页：帖子 128 页、审计 86 页、成员 347 页）。

### 1.4 错误码分段（shared `ERROR_CODES` 唯一来源，随模块扩充）
| 段 | 范围 | 场景（原型锚点） |
| --- | --- | --- |
| AUTH- | 1001–1999 | 登录/验证码/锁定/2FA（AUTH-1002 锁定：5 次锁 15 分钟） |
| FORUM- | 2001–2999 | 版块/帖子/回帖（FORUM-2001 专属版块游客拦截；NET-游客状态→未报名拒绝签到） |
| ACT- | 3001–3999 | 报名/候补/核销（ACT-3001 已满转候补提示、ACT-3002 重复报名、ACT-3003 超出停改窗口） |
| RWD- | 4001–4999 | 签到/赠送/账务（RWD-4001 草稿超限属 FORUM、RWD-4002 赠送超上限 1000） |
| MOD- | 5001–5999 | 举报/处置（MOD-5001 重复举报已合并 P9-07） |
| NET- | 9001–9999 | 网络层（NET-1004 超时——原型锚点） |
| SYS- | 5000–5999 | 系统内部（SYS-5000；看板统计服务 BI-500 保留别名） |

### 1.5 权限级别（接口表中的「权限」列）
`P0 游客` · `P1 登录` · `P2 成员`（入会通过）· `P3 版主（可限版块作用域）` · `P4 组织者` · `P5 管理员`。所有接口服务端逐个鉴权（NFR-09）；P2+ 接口对禁言/封禁状态做行为级拦截。

## 3. 契约落地

- `packages/shared/src/contracts/enums.ts`：本契约全部状态枚举（与数据库 §1.4 一致），前后端 import 唯一来源；
- `packages/shared/src/contracts/pagination.ts`：`PageParams` / `PageResult<T>`；
- OpenAPI：NestJS Swagger 随各模块实施产出（`/api/docs`），本文件为人工评审基线。
