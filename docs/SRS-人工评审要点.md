## 二、重点评审项（按章节）

### 1. 变更需求（SRS 3.7，最高优先级——本次唯一 PRD 外新增，需需求方确认口径无误）
- [ ] FR-G1 每日签到：每日一次、经验值数值待确认（P9-16/17）、首版无连续奖励是否符合预期；
- [ ] FR-G2 等级由经验值决定：活动结束后**按出勤记录对出席者**统一发放经验+积分（未出席不发放）是否符合预期；发放触发方式默认"活动结束自动"（P9-18）；
- [ ] FR-G2 等级仅荣誉展示、不解锁权限（N6）；贡献值与等级彻底解耦（C5/R10 变更）是否确认；
- [ ] FR-G3 管理员赠送：仅管理员、站内通知、留痕、单次上限可配置（P9-16）；
- [ ] 账务模型 4.9：经验值/积分只增不减、无消费场景——确认当前无需兑换/扣减功能。

### 2. 状态机与流程（SRS 4）
- [ ] 4.1 用户账号：禁言仅限发言、封禁禁止登录；注销冷静期 30 天可撤销；
- [ ] 4.5/4.6 活动：报名截止→进行中→已结束→奖励已发放的链路与 4.6 出勤状态闭环是否完整；
- [ ] 4.3 内容状态："先发后审"口径下编辑重新校验的迁移路径。

### 3. 数据概念模型（SRS 5）
- [ ] 实体清单 23 项是否有遗漏（仅概念级，表结构在阶段 6）；
- [ ] 经验值流水/积分流水/签到记录/等级档位 4 个新实体的属性完整性。

### 4. 非功能需求（SRS 6）

- [ ] 6.4 兼容性、6.5 备份策略：均为建议基线（P9-01/02），评审时确认或给出替代方案。
