## 二、核心业务主链路（点击走查路线）

```
G9 登录 → G10 注册(验证码) → M1 入会申请 → A1 二次验证 → A3 入会审核(通过)
→ G1 首页(成员态) → M2 发帖 → M3 帖子详情(回帖/点赞/@)
→ M7 每日签到(递增+补签) → M8 我的报名 → G5 活动详情(报名/候补)
→ O3 签到核销 → O4 出勤统计(奖励自动发放) → M5 个人主页(等级提升)
→ A11 赠送经验值 → M4 通知中心(收到通知)
→ M15 举报 → A6 举报工单(处置) → A10 审计日志(留痕)
```
