```
G9 登录 → G10 注册(验证码) → M1 入会申请 → A1 二次验证 → A3 入会审核(通过)

```

## 四、修订记录

### UI 契约修订 v1.1（2026-10-07 · 方案 C 减法精致化，用户确认）

保持暖橙基调（背景 #FFF7ED、主色 #F97316）与信息结构不变，仅做视觉减法，涉及全部 41 页：

| 修订项 | v1.0 | v1.1 |
| --- | --- | --- |
| 装饰性 emoji | 约 40+ 处（标题/按钮/导航/徽章/空状态/侧栏） | 全部清除；语义符号改文字（赞/评论/举报/收藏/置顶） |
| 图标 | emoji 充当 | 统一彩色图标：微软 Fluent Color Icons（MIT，`assets/jys-icons.js` 本地内联 SVG），经 `jysIcon()`/`data-jys-icon` 渲染于顶部导航/后台侧栏/切换器/空状态/提示横幅；语义缺口以同集合近似图替代（游戏→puzzle、火焰→trophy、info→question-circle 等）；原删除 emoji 的位置（版块名/栏目标题/CTA/认证页标题）已恢复对应彩色图标；点赞计数/按钮用 heart（Fluent Color 无拇指图标的同集合替代）、收藏/加精用 star，计数文字统一为「12px 图标+数字」；编辑器表情按钮取同厂 Fluent Emoji Flat 笑脸（唯一跨集合特例） |
| 渐变 | hero/封面/签到卡/主页头部/奖励卡/Logo 等 linear-gradient | 全部改纯色或极淡单色块；例外：骨架屏 shimmer（功能性动效）保留 |
| 圆角 | 卡片 16px、按钮/输入 8px、容器 12px | 卡片 10px、容器 8px、按钮/输入 6px；`rounded-xl` 类弃用（≤8px） |
| 阴影 | 多层暖调投影 | 收敛为单层微投影；卡片悬停位移 ≤1px，主按钮去悬浮位移 |
| 徽章 | 常规态彩色（绿/蓝/橙底） | 常规态灰底深灰字；彩色仅异常态（审核中/候补/禁言=琥珀，删除/封禁/驳回=红） |
| 头像 | 双色描边环（.jys-avatar-ring） | 移除描边环，回归纯色底+首字 |

- 涉及资产：`assets/tokens.css`（令牌层）、`assets/jys-icons.js`（新增，Fluent Color 彩色图标本地资源）、`assets/prototype.js`（新增 `jysIcon()` 图标渲染与占位填充）、41 页 HTML（批量语义替换 + 图标占位）、`design-system.html`（新增「契约修订 v1.1」章节与图标集样例）、`screenshots/`（全站重截）。
- 校验：装饰 emoji 与 `linear-gradient` 在 HTML 中 grep 清零；`node --check` 通过；主链路 16 站点点击走查不受影响。

### 等级系统增补（2026-10-07 · 原型走查中需求方确认，对应 PRD v1.2 / SRS v1.1 增补）

- 等级由 5 档扩展为 **Lv1–20，分 5 大段位**：见习 Lv1–4 / 常驻 Lv5–8 / 活跃 Lv9–12 / 元老 Lv13–16 / 传奇 Lv17–20；升级所需经验随等级递增——Lv n→n+1 需 100×n 经验（累计 50×n(n−1)，Lv20 需 19,000，后台可配置）。
- 等级展示改「**段位框**」样式（数字色块+内圈白环+段位名）；帖子主楼与回帖楼层均展示段位名；个人主页（自己/他人）与签到页附升级进度微条。
- Mock 数据同步重映射：北漠 Lv18 传奇（经验 16,200）、阿茶 Lv14 元老（9,640）、提瓦特钉子户/星野子/南栀 Lv10 活跃、夜风 Lv6 常驻（1,864，距 Lv7 61%）、咸鱼要翻身 Lv5 常驻、孤屿 Lv2 见习。
- 涉及：tokens.css 等级令牌、9 个页面、design-system 等级样例、PRD v1.2 C7、SRS FR-G2 规则 3/6。
